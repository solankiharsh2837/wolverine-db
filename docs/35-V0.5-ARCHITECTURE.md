## System Responsibilities

- **WolverineDB**: Guarantees whether database state can be cryptographically trusted.
- **Wolverine Runtime**: Tracks what execution context and user session caused the state transition.
- **AEGIS**: Investigates what the verified observations mean in a broader threat landscape.
- **Wolverine Sentinel**: Synthesizes cross-layer correlation graphs and formulates non-destructive recovery proposals.
- **Cryptographic Policy Gate**: Enforces multi-party Ed25519 authorization before restoring provable state.
