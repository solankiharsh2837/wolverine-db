## 2. Subsystem Map & Key Responsibilities

### `src/wal/` — WAL Ingress & Normalization
- **[`decoder.ts`](../src/wal/decoder.ts)**: Decodes raw database WAL frames into structured table mutation events (`INSERT`, `UPDATE`, `DELETE`).
- **[`normalizer.ts`](../src/wal/normalizer.ts)**: Canonicalizes column values, data types, and timestamps into deterministic mutation tuples.
- **[`receiver.ts`](../src/wal/receiver.ts)**: Ingress socket / stream listener capturing live database replication events.

### `src/crypto/` & `src/binary/` — Deterministic Cryptography
- **[`c14n.ts`](../src/binary/c14n.ts)**: Strict JSON canonicalization (deterministic key sorting, UTF-8 normalization, no whitespace).
- **[`merkle.ts`](../src/crypto/merkle.ts)**: Cryptographic Merkle Tree construction and membership proof generation.
- **[`hash.ts`](../src/crypto/hash.ts)**: Domain-separated SHA-256 hash calculations and `timingSafeEqualHashes` comparisons.
- **[`approval.ts`](../src/crypto/approval.ts)**: Ed25519 asymmetric signature generation and verification for customer approvals.

### `src/postgres/` — PostgreSQL Integration Layer
- **[`adapter.ts`](../src/postgres/adapter.ts)**: PostgreSQL client connection pool, logical replication management, and nonce queries.
- **[`schema.ts`](../src/postgres/schema.ts)**: SQL DDL defining `wolverine_sys` schema and `wolverine_sys.approval_nonces` table.
- **[`nonce_store.ts`](../src/postgres/nonce_store.ts)**: `PostgresNonceStore` implementing durable replay protection with SQL `23505` handling.

### `src/trust_network/` & `src/runtime/` — BFT Trust Network
- **[`gateway.ts`](../src/runtime/gateway.ts)**: `TrustGatewayServer` authenticating customer signatures, dispatching to validators, and binding ledger records.
- **[`consensus.ts`](../src/trust_network/consensus.ts)**: `TrustConsensusEngine` aggregating validator attestations into `QuorumCertificate` tokens.
- **[`ledger.ts`](../src/trust_network/ledger.ts)**: `WolverineTrustLedger` appending finalization records with secondary index lookups.
- **[`validator.ts`](../src/trust_network/validator.ts)**: `TrustValidator` validating commitment signatures, sequences, and issuing signed attestations.
- **[`proof.ts`](../src/trust_network/proof.ts)**: `PortableTrustProofGenerator` and `OfflineTrustProofVerifier`.

### `src/sentinel/` — Behavioral Anomaly Detection & Policy Gates
- **[`policy_gate.ts`](../src/sentinel/policy_gate.ts)**: `PolicyGate` enforcing scope bounding, WORM immutability, EVM anchor verification, and blast radius caps with TOCTOU defense.
- **[`anomaly_engine.ts`](../src/sentinel/anomaly_engine.ts)**: Statistical anomaly detector monitoring transaction velocity and schema drift.
- **[`advisor.ts`](../src/sentinel/advisor.ts)**: Autonomous repair advisor generating `AdvisoryRecoveryProposal` objects.

### `src/reconstruction/` & `src/continuous_reconstruction/` — State Recovery
- **[`continuous_engine.ts`](../src/continuous_reconstruction/continuous_engine.ts)**: Continuous verified state reconstruction coordinator.
- **[`dependency_graph.ts`](../src/continuous_reconstruction/dependency_graph.ts)**: Transaction foreign-key and causal dependency graph.
- **[`frontier.ts`](../src/reconstruction/frontier.ts)**: Tracks the verified state frontier and sequence boundaries.
- **[`replay_engine.ts`](../src/reconstruction/replay_engine.ts)**: Replays verified mutation sequences against clean checkpoint baselines.
