# WolverineDB v0.2 Threat Model & Security Boundaries

This document formalizes the expanded threat model for WolverineDB v0.2, addressing new trust boundaries introduced by logical decoding (WAL) and external checkpoint stores.

## Threat Actors & Attack Vectors

| Attack Vector | Attacker Capability | Mitigation in v0.2 | Result |
| :--- | :--- | :--- | :--- |
| **Direct DBA State Tampering** | Modifies table data directly in PostgreSQL | External checkpoint Merkle root comparison | **Split-Brain Detected (`CRITICAL_DIVERGENCE`)** |
| **Trigger Disabling** | Executes `ALTER TABLE DISABLE TRIGGER` | WAL capture continues reading directly from transaction log | **Capture Preserved** |
| **History Deletion** | Deletes rows in `wolverine_sys.changes` | External Checkpoint contains unalterable change chain head | **Tampering Detected** |
| **WAL Slot Interruption** | Drops or pauses replication slot | LSN acknowledgment tracking; alert on replication lag | **Reconnection & Catch-Up** |
| **WAL Event Truncation** | Forcefully drops WAL segments | Verifier detects missing sequence / chain broken | **Incomplete Stream Detected** |
| **Checkpoint Substitution** | Attacker substitutes external checkpoint file | Checkpoint canonical digest recalculation fails | **Digest Mismatch Rejected** |
| **Checkpoint Rollback** | Attacker presents older valid checkpoint | Commit sequence monotonicity check (`commit_seq`) | **Stale Checkpoint Rejected** |
| **S3 Tampering** | Attacker tries to overwrite S3 checkpoint | S3 Object Lock (Compliance Mode) rejects delete/put | **Write Blocked by Cloud Policy** |
| **Capture Engine Disagreement** | Trigger capture differs from WAL capture | Automated equivalence comparator (`WDB-0014`) | **Discrepancy Flagged** |
| **Unauthorized Recovery** | Compromised admin attempts unauthorized restore | Multi-party Ed25519 signature + separation of duties | **Rejected (`WDB6xx`)** |
