# Wolverine Distributed Trust Runtime (v0.9.0)

WolverineDB v0.9 moves from in-process protocol simulation to an **independently running distributed network runtime**.

```text
                 CUSTOMER A
                     │
              Wolverine Agent
                     │
                     │ HTTP / TLS Transport
                     ▼
             ┌───────────────┐
             │ Trust Gateway │
             └───────┬───────┘
                     │
          ┌──────────┼──────────┐
          ▼          ▼          ▼
       Validator  Validator  Validator
       Node #01   Node #02   Node #03
          │          │          │
          └──────────┼──────────┘
                     │
                 QUORUM
                     │
                     ▼
              TRUST LEDGER
                     │
          ┌──────────┼──────────┐
          ▼          ▼          ▼
       Replica    Replica    Replica
       Node #01   Node #02   Node #03
```

## Runtime Components
1. **Trust Gateway**: Ingestion router, tenant authenticator, and validator dispatcher.
2. **Validator Daemons**: Standalone network nodes hosting Ed25519 signing keys.
3. **Ledger Replicas**: State machine replication cluster persisting finalized consensus blocks.
4. **Evidence Agent Client**: Customer-side HTTP client with local outage queueing.
