# WolverineDB v0.3 Architecture: External Cryptographic Anchoring & Multi-Database Capture

WolverineDB v0.3 introduces externalized public cryptographic anchoring and universal multi-database change capture across PostgreSQL, MySQL, and SQLite.

## High-Level Architecture

                  ┌──────────────────────────────────────────────┐
                  │            PUBLIC TRUST DOMAIN               │

## Core Principles

1. **Off-Chain Evidence, On-Chain Commitment**: The blockchain receives only 32-byte cryptographic commitments (`WDB:ANCHOR:v1:<checkpoint_digest>`).
2. **Cross-Domain Integrity**: Independent verification across live database, external object vault (S3/WORM), and public blockchain anchors.
3. **Multi-Anchor Consensus**: Enforces $M$-of-$N$ quorum verification policies.
4. **Universal Database Capture**: PostgreSQL, MySQL, and SQLite all normalize into the exact same canonical binary encoding (`WDB-0002`) and SHA-256 hash chains (`WDB-0003`).
