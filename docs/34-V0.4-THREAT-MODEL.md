# WolverineDB v0.4 Threat Model & Adversarial Analysis

This document defines the security boundaries and threat model for WolverineDB v0.4 Sentinel and self-healing mechanisms.

## Threat Actors & Defense Matrix

| Threat / Attack Vector | Attacker Capability | Sentinel & Policy Gate Mitigation | Security Result |
| :--- | :--- | :--- | :--- |
| **Compromised DBA Direct Edits** | Modifies user roles/balances out-of-band | Out-of-window anomaly detection + state Merkle root divergence | **Incident Flagged & Proposal Generated** |
| **Rogue / Hallucinating AI Model** | AI proposes destructive or fraudulent recovery payload | Deterministic Policy Gate asserts external anchor matching + bounded scope | **Invalid Proposal Rejected (`WDB5xx`)** |
| **Baseline Poisoning** | Attacker attempts to whitelist unauthorized scopes in baseline | Domain-separated baseline SHA-256 hash validation (`WDB-0031`) | **Baseline Tampering Detected** |
| **Autonomous Rollback Hijack** | Attacker tries to trigger unapproved recovery | Mode enforcement defaults to `APPROVAL_GATED_EXECUTE` requiring Ed25519 signatures | **Unsigned Recovery Aborted** |
| **Partial History Reconstruction** | Attacker damaged local history tables | Policy gate links restoration directly to externally proven checkpoint | **Provable Recovery Executed** |
