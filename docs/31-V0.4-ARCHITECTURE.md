# WolverineDB v0.4 Architecture: Sentinel & Self-Healing Security

WolverineDB v0.4 introduces Sentinel: an advisory behavioral anomaly detection and policy-gated self-healing security plane that cooperates with the deterministic cryptographic core.

## Trust Hierarchy

```text
                  ┌───────────────────────┐
                  │    External Anchors   │
                  │  EVM / WORM / S3      │
                  └───────────┬───────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────┐
│                 WolverineDB Core                  │
│                                                  │
│ WAL → History → Hash Chain → Merkle → Verify   │
└──────────────────────┬───────────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────────┐
│              Wolverine Runtime                   │
│                                                  │
│ Context → Provenance → Execution → Incidents   │
└──────────────────────┬───────────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────────┐
│                  SENTINEL                        │
│                                                  │
│ Baseline → Features → Anomaly → Correlation    │
│                         │                        │
│                         ▼                        │
│                  AI Explanation                 │
└──────────────────────┬───────────────────────────┘
                       │
                       ▼
                RECOVERY PROPOSAL
                       │
                       ▼
             DETERMINISTIC POLICY
                       │
                  Ed25519 Quorum
                       │
                       ▼
                  RECOVERY ENGINE
                       │
                       ▼
              VERIFY + RE-ANCHOR
```

## System Boundaries

- **State Truth**: Guaranteed mathematically by WolverineDB Core (WAL, RFC 8785 canonical JSON, SHA-256, Merkle trees).
- **Execution Truth**: Tracked by Wolverine Runtime (request context, session provenance, telemetry).
- **Advisory Intelligence**: Provided by Wolverine Sentinel (behavioral baseline deviation, incident explanations, proposed restoration plans).
- **Gating Authority**: Enforced by the Deterministic Policy Gate & Multi-Party Ed25519 Approvals.
